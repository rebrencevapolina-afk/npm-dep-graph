## Общее описание

CLI-приложение на Python для построения и визуализации графа зависимостей пакетов **npm** (JavaScript). Приложение позволяет:

- Загружать конфигурацию из YAML-файла.
- Получать информацию о прямых зависимостях заданного пакета из реестра npm.
- Строить транзитивный граф зависимостей с учётом максимальной глубины.
- Находить обратные зависимости (пакеты, которые зависят от заданного).
- Визуализировать граф с помощью языка диаграмм D2.

Проект выполнен в рамках дисциплины **«Конфигурационное управление»**.

## Технологии

- **Python 3.10+**
- **PyYAML** — парсинг конфигурации
- **requests** — HTTP-запросы к реестру npm
- **D2** — язык диаграмм для визуализации графа
- **pytest** — тестирование

## Установка и запуск

### 1. Установить зависимости

    py -m pip install -r requirements.txt

### 2. Создать config.yaml

    cp config.example.yaml config.yaml

### 3. Запустить приложение

    py -m src.main

### 4. Запустить тесты

    py -m pytest tests/ -v

Ожидаемый результат: **26 passed**.

## Формат config.example.yaml

    package_name: "express"
    repo_url: "https://registry.npmjs.org"
    test_mode: false
    max_depth: 3

## Этап 2. Сбор данных

Приложение запрашивает прямые зависимости пакета из npm registry (https://registry.npmjs.org).

## Этап 3. Построение графа

При `test_mode: true` приложение читает локальный YAML-файл и строит граф зависимостей от заданного пакета методом **BFS с рекурсией**. Учитывается `max_depth`, обрабатываются циклы.

## Этап 4. Обратные зависимости

Приложение находит пакеты, которые зависят от заданного пакета (обратные зависимости).

## Этап 5. Визуализация (D2)

    py -m src.main --visualize

Создаются файлы `graph.d2` (текстовое описание) и `graph.svg` (изображение).

### Сравнение с npm ls

Оба инструмента показывают одинаковый набор прямых зависимостей `express`. Возможные расхождения — из-за версий: мой инструмент берёт `latest`, а `npm ls` — установленную версию.
